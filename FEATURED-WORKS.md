# Featured artwork selections

Each artist has an explicit featured work, used consistently in the index card, profile and comparison view. It is selected independently of gallery order. New additions to a gallery cannot silently replace it.

Fame is not an objective universal ranking. Museum/foundation evidence supports an iconic, widely recognised work where possible. When no single work has an established claim, a representative work from the artist’s signature series is identified honestly. Selections remain appropriate to Grade 7–8 classroom study.
